Dev workspace

Project, duyệt lệnh và explorer của conversation hiện tại.

Hướng dẫn: từ yêu cầu đến chạy local
  1. Nhập /develop yêu cầu dự án Python trong chat.
  2. Trên ZIP trả về, chọn Chuẩn bị dự án → xem cây file → giải nén.
  3. Trong Luồng chạy dự án: duyệt cài dependencies (nếu có), rồi duyệt Chạy hoặc Kiểm tra.
  4. Xem log, mở URL khai báo nếu là web app. Dừng task trước khi sửa source. Server có timeout tối đa600giây.
  5. Chọn Soạn yêu cầu sửa; upload log riêng bằng /upload nếu cần, rồi gửi source qua /project. ZIP sửa có thể xem diff rồi apply vào project cũ để giữ venv, hoặc nhập workspace mới.

Source chỉnh sửa, venv và bản sao chạy nằm riêng. Mỗi lần duyệt chạy dùng đúng revision đã xem; file sinh ra khi chạy nằm trong thư mục lượt chạy.
